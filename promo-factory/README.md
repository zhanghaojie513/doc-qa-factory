## 美术和真实性

暖白无缝台面、磨砂铝、炭黑橡胶、橙红令牌。圆角与倒角真实建模，软箱环境反射、接触阴影与方向光建立层次；相机在微距、三分之四、阅读高角度与全景之间移动。没有轮播卡片，没有粒子，没有把文字拉到尾角。

工厂是工作流程的物理隐喻，片中标注“工作流程示意 · 演示手册”。事实来自README、demo-manual.docx和manual-config.json。M010、60天、F0和原图来自虚构演示手册。六项校验是机制示意，未伪造运行终端。未装载或改动知识库。

## 文件与许可

`comp.html` / `factory.js`：确定性整片；`?play` 播放，`?t=6.8` 定格。`motion.js`：onetake曲线与动作库。`look.js`：内嵌字体。`score.py`：声音事件驱动的拟音与原创配乐。`draft.mp4`：1080p30与真实快门运动模糊。接受剪辑前不渲染4K。

声音以机械触点、纸、木和金属为主体，音乐克制。Kenney Impact Sounds官方页面标记CC0：https://kenney.nl/assets/impact-sounds 。选中的源文件和许可将一并保存，避免使用案例成片混音。Three.js r180（MIT）、字体SIL OFL、onetake许可随文件交付。
