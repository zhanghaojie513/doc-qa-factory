# 每个答案，都有来处

模式：自主自由创作。用户授权从头创作、不受旧片制约。独立工程，旧成片和业务知识库不修改。

## 产品简报与决策

来源：项目 README.zh-CN.md、references/operations.md、troubleshooting.md、build/make-demo-docx.mjs。产品是 Agent Skill，没有独立 Web UI。观众为有手册问答需求的团队与 Agent 使用者；目标是理解其差异并安装。

|需求|执行|

## 视觉方向

考虑：暗色证据实验室、纸张工厂、薄荷绿编辑台。选择第三种：social-card.png 的薄荷绿 #a7d2be、深绿 #193f31、暖黄 #ffdc72、珊瑚 #ff7052。暖白 #f8f6ed 作为文档面。字体 Microsoft YaHei（中文）/ Arial（英文）/ Consolas（编号）；原品牌卡无可提取矢量字体，沿用朴素无衬线气质。标题112–140，叙事字幕64，辅助36–44，行高1.2，负字距-0.035em。80px外边距、32px网格、圆角24–36。黑绿细线连接答案和证据，纸卡浅影，禁止霓虹、手持晃动、群体扫光。

动效性格：专业、亲和、确定。主要入场21–30f，bezier(0.16,1,0.3,1)，普通入场无弹跳；结尾沿镜头卡落地过冲。每镜落定留读。设计样张 styleframes.html 先于视频代码生成并截图检查。

本产品无现有Web界面，故全部功能卡是独立叙事组件，不声称复刻产品UI。原创范围：前六镜的书本、证据连线、手册版本图和检查门禁；风险是可能被误读为产品界面，因此全片持续标注“机制演示 · 虚构示例”。不跑calibrate、不修改已装载手册。

镜头卡准确源码：skill/demos/typography/marker-underline-title/MarkerUnderlineTitle.tsx；skill/demos/outro/outro-group-photo-launch/OutroGroupPhotoLaunch.tsx。已完整阅读两卡与源码，摘取运动数学重新蒙皮。Gallery索引摘录保存在 references/library-selected.json；预览参考保存在 references/。前六镜原创，不套未读取的卡。结尾用四个能力代表元素取代9个页面切片，以符合本产品功能粒度；已读卡的12f飞行/过冲/4°crane/42f字标时序保留。

规则取舍：Q7暗金属非本品牌，使用深绿边界镜头作为明暗反差；C3无3D页面注记；S1选择较克制音乐，按内容节奏编排，不以整画面冲击逐拍卡点。辅助工程标注是纹理层，小字不承载必要信息。安装命令为辅助44px。

终检修正：机制标签36px，安装命令44px，Head显式使用品牌字体；结尾补准确demo SpeedBlur方向模糊、36f起缓推、2–14f光带；声音改为CC0 subtle riser → cinematic impact → fashion shimmer，峰值分别钉在结尾42f、42f、70f（riser提前铺入，impact同峰接力）。统一补偿输出偏移1.28f，五探针见out/audio-offset.json，源峰值和编码偏移分账。BGM为Tonight / Michael Ramir C.，Mixkit库许可记录随public/audio/BGM-CREDITS.md交付。音频工具可测量但无法提供可靠主观试听，报告保留此限制，不声称已试听。

声音取舍：六项校验呈现的是门禁机制清单，不模拟用户操作；不为每项添加提示音，以免六连音像真实运行反馈。提问打字无键盘拟音，作为无手部的概念输入，主声音给纸张和证据移动。结尾不用全画面闪白或震屏，光带只12% overlay，金尘20粒固定参数，舞台光为品牌色径向光。

双版本封装说明：bgm:false已从同一Remotion时间线独立渲染，保留SFX；独立回验发现两轮H264编码产生极小压缩差异（SSIM 0.999828），无内容错版。为交付逐帧完全一致的视频，最终无BGM版仅复用主片视频流并直接复制bgm:false渲染音轨，未分离混音、未删除SFX、未重编码或改时间线。原始无BGM渲染保留out/qa/promo-nobgm-rendered.mp4用于追溯。此封装取舍以满足A8视频精确一致为依据。
